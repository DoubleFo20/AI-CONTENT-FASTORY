# TH/EN localization contract

Thai (`th`) is the default; English (`en`) is the only additional V1 locale. A small typed
dictionary requires identical keys, preventing partial locale coverage. Only public locale
and the new content-display preference may be stored in localStorage; private projects/tokens must not be.
Set document.lang; use Intl.DateTimeFormat/NumberFormat for locale-aware display.

Translate navigation, setup/login, forms, buttons, placeholders, validation/error messages,
queue statuses, progress, empty states, offline notice, file-import instructions and export
states. Server errors use stable codes; the client maps codes to both locales, not raw
provider/OS errors. Backend content schemas use {th,en}; the new display mode chooses
TH/EN/TH+EN independently of UI locale. The current Phase1 client still follows UI locale
until Codex implements this presentation revision.
Technical IDs and model names remain proper identifiers; no English-only product chrome.

Thai scene explanations and English Google Flow prompts intentionally remain in their
specified languages regardless of UI locale. Label that distinction in both locales. Never
translate an English Flow prompt implicitly or alter its continuity references. Support
Thai line breaking, long English labels, keyboard interaction and a 44px locale switch.

Coverage validation compares dictionary keys, verifies known error codes, confirms document
language and renders critical setup/login/story/queue screens in both locales. Translation
coverage does not replace browser layout checks at 360/768/1440px or native-language review.

## Design revision 1 — content display

Keep API Locale limited to th/en. Add client-only content display th/en/both, independent
from UI locale. Thai is the first-use content default; TH+EN stacks Thai first and labels
English explicitly and uses lang attributes on both blocks. Public preference may use acf-content-mode; no story/token is persisted with
it. Existing acf-locale remains compatible. Switching keeps selected story/scene context
and never generates, translates or changes the saved package.

Thai explanation and exact English prompt remain visible in their languages in every mode.
Use คัดลอกพรอมป์ต์อังกฤษ / Copy English Prompt. Story/background/location/narration/title/
logline/hook can stack; proper names/English visual descriptions retain their language.
New navigation/planned/unknown/storage/review states need matching typed dictionary keys;
UI_SPEC.md proposes them. No third backend locale or raw provider/OAuth errors in UI.
