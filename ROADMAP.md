# Roadmap

## Phase 0 — definition and handoff

Freeze V1 PRD, IA/page inventory, UX/responsive/i18n requirements, system/AI/security
architecture, data/API contracts, dependencies and governance. Validate links, required
artifacts and scope; commit. Mark Antigravity ready as soon as these are stable.

## Phase 1 — local foundation and independently testable pipeline

1. Scaffold npm/TypeScript tooling and shared contracts (Root).
2. Backend auth, local data model, ownership, project state machine and persistent queue.
3. Parallel functional TH/EN client shell, first-run owner setup and dashboard.
4. Structured AI provider: exactly ten ideas, exactly one selection, selected expansion,
   four bibles, scene planning and Google Flow prompt pack.
5. Validated clip import, deterministic FFmpeg assembly, authenticated preview and MP4 export.
6. Independent security review, API regression tests, typecheck/lint/build, browser/mobile/PWA QA.
7. Update evidence and commit a runnable checkpoint. No production release claim.

## Phase 2 — approved design integration and real creative acceptance

Read Antigravity's approved DESIGN_SYSTEM and UX specifications; implement the approved
design; return for visual QA. With Owner-controlled Flow clips, verify identity/continuity,
prompt usability and the final edited result. Resolve live-provider access/account/billing
issues without blocking unrelated local work. Deployment remains a separate Owner decision.

## Later — secondary modules

Use the shared module registry and media/project/job contracts for Product Review Factory,
Kids & Toy Factory, Investment Lab, Media Library, Publish and Settings. Each receives its
own PRD and acceptance gate. No secondary implementation in the Story Factory milestone.
